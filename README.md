# Hy3 Algorithm Process Evaluation

基于 Hy3 的算法竞赛解法过程评估与错误定位项目。

## 项目负责人

郭昊杨，福州三中信息学竞赛选手，NOIP 省一等奖。

## 任务方向

本项目选择“犀牛鸟开源 · 实战任务 2：可验证场景——过程评估与错误定位”中的算法竞赛方向。

项目将针对给定算法题目、约束、测试数据、结构化解法说明和 C++17 代码，评估：

- 最终程序是否通过独立测试；
- 解法思路是否正确；
- 正确性论证是否成立；
- 时间与空间复杂度是否正确；
- 边界、溢出、下标等处理是否充分；
- 首个错误步骤及错误类型；
- 最终答案正确但过程无法支撑结论的情况。
