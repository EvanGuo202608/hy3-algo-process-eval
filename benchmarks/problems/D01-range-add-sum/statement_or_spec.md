# Range Add Range Sum

给定长度为 `n` 的数组 `a`，需要处理 `q` 个操作：

- `1 l r x`：将区间 `[l, r]` 内每个数都加上 `x`；
- `2 l r`：查询区间 `[l, r]` 的元素和。

所有区间端点都是 1-indexed 且闭区间。

## 输入格式

第一行两个整数 `n q`。

第二行 `n` 个整数，表示初始数组。

接下来 `q` 行，每行是一个操作。

## 输出格式

对每个查询操作输出一行区间和。

## 约束

- `1 <= n, q <= 200000`
- `-10^9 <= a_i, x <= 10^9`
- 查询答案可能超过 32 位整数范围，必须使用 64 位整数。

## 说明

区间更新时，如果当前线段完全被覆盖，节点和应增加 `x * len`，并记录 lazy add 标记；访问子区间前必须把 lazy 标记下传到子节点。
