# Minimum Network

给定一个包含 `n` 个点、`m` 条无向带权边的图。你需要选择一些边，使得所有点连通，并且所选边权值之和最小。

如果无法使所有点连通，输出 `orz`。

## 输入格式

第一行两个整数 `n m`。

接下来 `m` 行，每行三个整数 `u v w`，表示一条连接 `u` 和 `v`、权值为 `w` 的无向边。

## 输出格式

如果存在连通方案，输出最小边权和；否则输出 `orz`。

## 约束

- `1 <= n <= 2000`
- `0 <= m <= 10000`
- `1 <= u, v <= n`
- `0 <= w <= 10^9`
- 允许重边和自环。自环不能帮助连接不同点。

## 说明

合法方案必须让所有点属于同一个连通分量。仅选择权值最小的若干条边并不一定正确，因为这些边可能形成环，无法连接新点。
