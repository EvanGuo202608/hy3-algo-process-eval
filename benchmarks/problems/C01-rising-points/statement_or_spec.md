# Rising Points

给定 `n` 个平面点 `(x_i, y_i)`。你需要选出一个点序列 `p_1, p_2, ..., p_k`，使得：

- `x_{p_1} < x_{p_2} < ... < x_{p_k}`；
- `y_{p_1} < y_{p_2} < ... < y_{p_k}`。

输出满足条件的最大 `k`。

## 输入格式

第一行一个整数 `n`。接下来 `n` 行，每行两个整数 `x_i y_i`。

## 输出格式

输出一个整数，表示最长二维严格上升点列长度。

## 约束

- `1 <= n <= 2000`
- `0 <= x_i, y_i <= 10^9`
- 点可能重复，也可能存在相同的 `x` 或相同的 `y`。

## 说明

本题的序列要求两个坐标都严格递增。相同 `x` 的点不能同时出现在合法序列中，相同 `y` 的点也不能同时出现在合法序列中。
